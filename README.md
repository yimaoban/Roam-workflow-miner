# 岗位工作流挖掘师（workflow-miner）

通过一对一顾问式访谈，帮职场人挖出岗位上"说不清、但天天在做"的隐性工作流——
包括那些默认在执行、却从没人写下来的判断规则、返工点与质量红线。

## 它能做什么
- 用四阶段访谈（筛任务 → 还原真实过程 → 挖隐知识 → 生成方案）带你梳理一项重复工作
- 把挖出的隐知识直接翻译成"明天就能用的提示词"和"人工检查清单"
- 明确划出 AI 可接管 vs 必须人工把关的边界

## 使用方法
1. 在 WorkBuddy 中安装本技能
2. 说："帮我挖一下我的岗位工作流" 或 "工作流访谈"
3. 跟着顾问式提问如实回答，约 15–25 分钟
4. 拿到《岗位AI工作流文档》
