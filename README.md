# Roam-workflow-miner
Uncover your job’s unspoken hidden workflow in the time of a milk-tea chat with AI.岗位工作流挖掘师。通过一对一顾问式访谈，帮职场人挖出岗位上说不清、写不出的"隐性工作流"（隐知识、判断规则、返工点、质量红线），最终产出一份《岗位AI工作流文档》，指导用户后续与AI协作的分工方式。当用户说"帮我梳理工作流""挖一下岗位隐知识""我想知道哪些工作能交给AI""我的岗位怎么跟AI配合""工作流访谈"等，或用户描述自己的日常工作想做成AI工作流时触发。不适用于用户只想写一条单次任务的提示词（直接写即可）。
